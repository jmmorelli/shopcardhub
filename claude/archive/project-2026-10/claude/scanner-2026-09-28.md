# Card Scanner — private v1 (2026-09-28, Mo in chat: "yes build it … camera roll also … good retention piece")

**What:** a private claude.ai artifact, "ShopCardHub Scanner" (https://claude.ai/artifact/QwQGKCH8hMvJaDZ7zieoWY), owner-only. It is not on shopcardhub.com, so no page freeze or R25 question comes up.
Photo (camera or camera roll, several at once) → Claude reads the card on the viewer's own account (`sample` capability, no API key, $0 spend) → matched against an embedded catalog of 891 cards → dated sold price + index membership → saved to "My cards" or "Hunting" (`db` collection `cards`).

**The price catalog is embedded at build time** from `data/indices.json` (all 11 tickers' baskets, weights, levels) and `data/feed/sold-marks.json` (read 2026-09-27; raw + graded). That covers every SV151 and TH26 card, the six Pokémon chase baskets, the BOW26 autos and Mo's catalog cards. It only refreshes when the page is republished. The page reads no asks (R20).

**Unmatched cards** are saved with `needsPrice: true`. A later pass (a session with ArtifactData + PriceCharting) writes `price: {p, label, b, d, src}` on the doc, and the page renders it.

**Honesty rules:** no price or estimate from the model (the prompt forbids it). The raw price is labelled "raw", and caveats show for reverse holo, parallels, serials, non-English cards and slabs without a graded sale.

**EPN:** eBay links on this page are plain, with NO affiliate tag. It is Mo's own buying tool, and self-clicks/self-purchases are forbidden by EPN. `customid=scan` belongs only on a future public version.

**Bridge to the site:** "Copy list for the ShopCardHub watchlist" writes lines in the `/watchlist` Paste-a-List format.

**Public version:** a "Scan" button inside `/watchlist`, after the Oct 26 freeze, only if the private one proves accurate at a card show. That needs a site-side vision call (spend → Mo) and is not queued.

Files: build script + source in the session workspace only (`build_catalog.py`, `scanner.src.html`). Rebuild = re-run against a fresh clone and republish to the same URL.
