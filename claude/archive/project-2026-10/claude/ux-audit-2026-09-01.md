# ShopCardHub UX audit — 2026-09-01

Full report (artifact): https://claude.ai/code/artifact/6d77b5b8-208e-4ddb-831c-94f31108e101
Method: 12 pages rendered headless at 1440 desktop + iPhone 13; DOM/perf probes; nav, mega-menu, mobile menu and Vault row→detail tested.

## Scorecard (/10)
Visual identity 8 · Content credibility 8 · Card imagery 1 · Mobile 3 · Vault funnel 5 · Motion quality 4 · Bugs/polish 4 · Performance 7

## Ranked findings
1. **No card images** — 0 `<img>` on 10/12 pages (1 on /watchlist, 6 on /pokemon-tcg-2026). Fix: shoot the COMC inventory, `/img/cards/{slug}.webp`, thumbnails in Vault rows + detail popup + Bowman blocks; holo-tilt hero card as signature.
2. **Mobile** — home 10,311 CSS px (15.5 screens); /bowman-bangers 27,239 px (41 screens) and its layout viewport stretches to 507 px (two tables without `overflow-x:auto`) so Safari renders the whole page at ~77%. Six stat tiles stack 1/row. 34/106 tap targets <40 px on home. Fix: wrap tables, cap hero at 100svh with board peeking, 3-col tiles, accordion essays + sticky prospect chip bar.
3. **Vault-path bugs** — mobile menu "Tuesday Tape →" has black text on black (`.m-cta` inherits filled-button color); "27 engine prices imported" toast covers table row; Vault detail title on mobile wraps one word per line (fixed 2-col header grid); chart "351" label overprints "TGT 340"; rank ghost "03" overprints price label on Bowman card #3; "Pulling live eBay listings…" can stick on desktop; mega-menu translucent (hero bleeds through).
4. **Vault not the hero** — homepage Vault boxes at ~1,200 px show "No cards tracked yet"; /watchlist table starts at 730 px desktop / 1.8 screens mobile behind 2 paragraphs + demo banner + 8 controls. Fix: live Vault strip under hero (sample data for new visitors, localStorage for returners); tool above the fold; demo → 3-step onboarding checklist; mobile columns Card·Last·7D·Trend; controls in bottom sheet; count-up + row flash + "since your last visit" diff.
5. **Motion = ambient noise** — 14 animations on home, 8 infinite; reduced-motion honored only on /bowman-bangers. Keep ≤2 ambient loops; add informative motion (count-up, row flash, chart draw-in, FLIP rank shuffle, view transitions, hover lift, skeletons).
6. **Bowman Bangers** — ranking buried under ~4,500 words; ranked table is 26 screens down on mobile; card layouts inconsistent (#1–2 centered price vs #3+ right). Fix: sortable board table first, essays as expanders, weekly update as 3 bullets, one card layout. FLIP rank-change animation with "was #n" badges.
7. **No return hook between Tuesdays** — add "since your last visit" movers (localStorage), daily Movers module, Notification-API push on target hits, replace static stats strip with Track Record proof (calls graded, hit rate).
8. Hero has 3 CTAs in 3 styles; reorder home: hero → Vault strip → Bowman board → Movers → guides → Tape. Drop "The Floor" copy and "What we write about" grid.
9. Muted gray rgb(90,120,128) on #07090C = 4.2:1 (under AA for 13 px); 8–9 px text on mobile. Lift to ≈rgb(122,150,158) (6.3:1), floor 11 px.
10. Floating "★ Track this card" shows on pages with no card (PSA guide, ROI calculator, research).
