## Idea 32 — Sell the case, not just the box: a "Cases →" link on every sealed row and sealed strip

1. **Title.** Case-level eBay link (own custom ID, no figure) beside every booster-box / ETB / hobby-box link.
2. **Mechanism.** `tools/build-sealed-rows.mjs` and `tools/build-buy-strip.mjs` gain an optional `case` object per sealed entry — a positive query ("prismatic evolutions booster box **case**", `titleMust` includes "case", the usual junk exclusions minus `-case -lot`) rendered as one short text link, *"Sealed cases →"*, after the existing box link, `customid=<ticker>-case` / `<page>-case`. **No price on it**: `TITLE_BAD_SEALED` exists precisely because lots and cases would corrupt a box mark, so the case link is a link, never a mark and never an index input. Scope: the sealed rows on the 5 Pokémon index pages (PRIS25, DR25, PB26, CR26/AH26, PF25 — 6 boxes per Pokémon booster-box case, 10 per ETB case, stated on the label) and the sealed-lander strips (`best-hobby-boxes-2026`, `bowman-chrome-baseball-2026`, `topps-chrome-baseball-2026`, `topps-definitive-basketball`, `bowman-sapphire-2026`; sports cases are 8–12 boxes). If #4 (adopted, deep-link the cheapest clean listing) lands first, the case link inherits it: cheapest single-case ask, deep-linked.
3. **Site synthesis.** The sealed rows (Sep 13), the R11 buy strips (Sep 17), `data/watchlist.json` sealed entries (a field on an existing entry, not a new tracked card), per-product EPN custom IDs. No new page, no new nav item.
4. **Evidence.** Internal, dated: the 30th release-night tape (Sep 16, STATE) found the cheapest way into the ETB was **multi-box lots** — $1,320/8 = $165/box and $2,060/10 = $206/box against a $175 single — i.e. the lot buyers were there on night one and our link could not send anyone to them. ## Idea 33 — Point $200+ single-card links at eBay's Authenticity Guarantee listings, and say so

1. **Title.** Authenticity-Guarantee-filtered deep links (own custom ID) for every single-card link whose target trades at $200 or more.
2. **Mechanism.** eBay lowered the trading-card Authenticity Guarantee threshold from $250 to **$200** in August 2026 (raw and graded singles, sports and TCG). For a buy-strip secondary, an engine-block "Top card" link or a body link whose card's current verified ask (or the strip's `title` card) is ≥ $200, the eBay search URL carries eBay's AG "Show only" filter and `customid=<page>-ag` (or `<card>-ag`), with the anchor text *"Authenticated on eBay →"* and a one-line factual note in the strip fine print: *"eBay authenticates single cards $200+ before delivery, at no cost to the buyer (eBay, Aug 2026)."* Links under $200 are untouched. The rule is a threshold on a number we already compute nightly, so it is a renderer condition, not a new page.
3. **Site synthesis.** The nightly engine's verified asks, the engine blocks, the buy strips (`build-buy-strip.mjs` already carries `LH_BIN=1` and the mandatory EPN param set — this adds one filter flag), per-link custom IDs. The `/api/comps` Browse API path can later prefer AG items (the Browse `Item` type carries an `authenticityGuarantee` object — https://developer.ebay.com/api-docs/buy/browse/types/gct:AuthenticityGuaranteeProgram) but that is a follow-on, not the first step.
4. **Evidence.** Threshold: Value Added Resource, Aug 1 (updated Aug 11) 2026, https://www.valueaddedresource.net/ebay-trading-card-threshold-packaging-updates/ — *"Eligible raw and graded single trading cards $200+ are now included"*, previously $250; the filter is a "Show only → Authenticity Guarantee" checkbox on eBay search (eBay community mentor, https://community.ebay.com/t5/Ask-a-Mentor/Authenticity-Guarantee-search-filter-whats-the-link-to-this-page/td-p/34537015). Internal: the money is already in this bracket — the two sales that made Aug 25–Sep 17 were **$1,950** and **$860** singles, both on phones, and the phone buyer landing on a search page is G3; a search page pre-filtered to authenticated listings is the trust-shaped version of the same fix. **No external evidence on conversion lift was found — reasoning only** on the effect size. Stumble declared: the cloud fetch of eBay search is 403, so the exact URL parameter for the AG filter was **not verified this run**; it must be read off the filter UI in a browser before anything ships (the site's `LH_BIN=1` / `LH_Sold=1` flags are the same family).
5. **Money math.** Lever: **$/click** — it only touches links whose basket is ≥ $200, so every click it changes is a $6+ commission click at 3%. ESTIMATE **+$5–$25/mo** — assumption: 10–20% of today's ~30 single-card clicks a fortnight are on $200+ cards and an authenticated landing converts one or two more of those a month than an unfiltered search does; the attribution split (`-ag` vs plain) is the first real read on whether trust copy moves the investor. Rung: **M0** contributor; M1 mechanism because it compounds with #30 (star-page engine blocks) and #31 (graded links), both of which produce $200+ links.
6. **Cost and Mo-time.** $0. Mo-time: 0.
