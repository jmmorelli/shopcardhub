## Set-index fix (commit 3b542ed) — "only a few cards show up"
Root cause: the eBay lookup searched category 212 (sports cards), so Pokémon names returned nothing and rows fell back to placeholders. Fix: `tools/price-engine/resolve-page-images.mjs` resolves every page marker once (TCG category 183454 for Pokémon; card-number matching tolerant of 090/084 vs 90/84; rarity codes stripped) into `data/card-images.json`. Re-run it whenever a list page's cards change: `node tools/price-engine/resolve-page-images.mjs [page.html]` (SITE_URL env optional). Client-side `byName()` uses the same rules as a fallback for visitor-added Vault cards.
