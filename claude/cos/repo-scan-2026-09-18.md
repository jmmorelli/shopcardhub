# Open-source Claude repos vs our site — what to adopt, what to copy, what to skip (overnight 2026-09-17/18)

**Ask (Mo, 2026-09-17 night):** "a bunch of free repos on GitHub you can utilize for Claude projects — look at our own website to see what we could add to increase retention OR help manage the backend more efficiently."

**Method.** Two agents, in parallel: one surveyed the ecosystem (fetched README/repo pages for ~40 repos; stars and activity are as shown at fetch, nothing installed or run), the other inventoried a fresh clone of `main` at `b018dfd` (read-only) for the retention loops and backend seams a repo could actually fill. This doc is the CoS ruling on the two reports. Every "adopt" below is either free or $0 with a one-time Mo approval; the budget rule (no spend until the site covers ~$300/mo) is respected throughout.

**The short version.** Most of the famous repos are prompt packs and orchestration frameworks that would add context cost and nothing our LANE-RULES can't say in a paragraph. Four things are worth installing, six patterns are worth copying into our own tools with no dependency at all, and the single biggest backend win — cloud runs being able to read GA4 without a browser — is one free Google service account away. The retention gaps are not repo-shaped; they are ten specific holes in our own code, listed in §3, and most of them are already scheduled under the return-user program.

## 2. Copy without installing (patterns → our own tools; all auto-approved, all $0)

1. **Verify-before-stop.** A Stop hook that exits non-zero when files changed and no pushLog line was appended in the session. Kills the "push without its own pushLog entry" defect that has now been caught three times.
2. **SessionStart freshness.** Five lines of bash: `git fetch -q && git rev-list HEAD..@{u} --count` ≠ 0 → print `STALE CLONE` and refuse. This is R2 as a hook instead of a paragraph.
3. **Path-scoped write guard.** PreToolUse rule: writes to `claude/cos/*` or `LANE-RULES.md` allowed only when `$LANE=cos`. The single-writer ruling, enforced mechanically.
4. **Generator round-trip assertion in CI** (from the inventory, not a repo): run every `build-*` on a clean tree, fail on any diff. Would have caught the RAIL strip on `auctions.html` and the DR25 TOTAL-row corruption.
5. **Doc-drift gate** `tools/doc-drift.mjs`: every repo path referenced in LANE-RULES / CHARTER / STATE must exist in `git ls-files`; every commit on `main` must carry `Task-key:` / `Authority:` trailers. Today: LANE-RULES says CHARTER.md is "in the repo" (it is not), STATE requires trailers (none of the last 8 commits carry them), `data/newsletter.json` lists 3 pages while 31 carry forms, and the cadence table omits the Integrity Watch. Each is a settled-item re-filing waiting to happen.
6. **Beacon block list as config**, one file, read by every QA path.
7. **Action-plan format for recommendations** (observation → change → falsifiability check → leading indicator). Adopted for the Ideas Desk (see `claude/ideas/README.md`) and for NEEDS-MO items.
8. **Drop retired rich-result schema**: FAQPage (retired May 2026) and HowTo JSON-LD should come off any page still carrying them — maintenance for a rich result Google no longer shows. One grep, one commit, next build session.

## 3. What the inventory found that no repo fixes — the retention holes in our own code

Ranked by return visits × eBay clicks. Most are already scheduled under the return-user program (W1–W6); the ones that are not are marked.

1. **`/` has zero eBay links at rest and zero click telemetry.** The bookmarked return surface (1m37s engagement) cannot be attributed in EPN or GA4: the only outbound links are the client-side Auction Desk rows, all tagged `customid=auctions` (colliding with `/auctions`), and `js/home.js` emits no gtag at all — no screen switch, rail click or eBay click on the dashboard is measured. Fix: `customid=home-auctions` via a query param on `/api/auctions`; a `click` event in `renderAuctions`; a listing-level eBay link on Markets/Movers rows from `prices-latest.json`. **Not scheduled — added to the Wed build session.** Under R11's spirit this is the biggest single conversion miss on the site.
2. **No "since last visit" on the dashboard.** The diff logic exists twice already (Vault `sch_vault_seen_v1`, board `sch_bb_rank_seen_v1`); `home.js` renders the market only. = W2 `HOME:mine`, Sep 22–28. Nothing new to decide.
3. **Search cannot find a card.** The nav `INDEX` is 101 page titles inlined into all 103 pages; zero card-level entries. = W1.
4. **Alerts fire only while the user is on `/watchlist`** (`new Notification` on load, no service worker, no push). The free half — a "N flips since your last visit" badge in the rail on every page from the same seen-map — is not gated on the 40-subscriber rule and should ship with W2.
5. **Email capture config drift**: `data/newsletter.json` lists 3 pages; 31 pages carry forms with 12 different `source` strings; the `/` form is at the bottom of a page whose visitors are the investors the ask should reach. = email program W1 ("move the ask to where investors already are"), plus make `newsletter.json` the generator input.
6. **★ Track is absent on the four surfaces investors return to** (`/`, `/indices`, `/auctions`, `/watchlist` — 0 `.sch-track-card`). W1 names `/auctions`; add the contract to `renderScreen` rows in `home.js` for the rest.
7. **The #1 lander is not in `data/buy-strip.json`.** `/pokemon-30th-anniversary-2026` passes §15 on a hand-placed module, so `buy-strip-health.mjs` never tests its ETB query. Add it `live:true` so the Monday Gengar beat owns it. **Not scheduled — one line, next push.**
8. **52 of 103 pages share `og/default.png`**; no per-board or per-card OG image, while the Tuesday lane is about to publish `og/x/board-latest.png` for the vendor. Set `og:image` on the 7 engine hosts to their own tape render. Small, after W3.
9. **No RSS/JSON feed of the nightly marks or the Tuesday Tape.** The cheapest word-of-mouth surface for an investor who won't give an email; emit `/feed.xml` from `board-history.json` + `calls.json` inside `build-home.mjs`. **Not scheduled — cheap; Wed build session, after item 1.**
10. **EPN attribution reality**: 99.6% of revenue lands in "No Custom ID" because the eBay app's universal-link handoff on phones drops `customid` (Sep 4 finding). Not fixable in HTML; every attribution-based ranking must split tagged vs untagged first.

## 4. Backend seams the inventory found (ranked by incidents prevented)

1. CI runs one gate of three (→ §1 item 2).
2. No `package.json`/lockfile; Playwright resolved via `npm root -g`, so a global mismatch silently skips the click gate. Fix: a `package.json` pinning `playwright` and an `npm run gates`.
3. **Two nightly writers to the same feed**: `vercel.json` still crons `/api/cron-snapshot` (legacy PriceCharting path, 08:00 UTC) fifteen minutes before `price-snapshot.yml` writes the same `prices-latest.json`. Fails closed only because its env vars are absent. Delete the cron entry; delete `api/ebay.js` (zero callers).
4. Dead loops with live endpoints: `api/decisions.js` writes a file nothing reads; `api/track-signal.js` counters are consumed by a prompt step, not code; `newsletter.mjs` still targets retired Kit inside the nightly workflow.
5. Marker-splice code re-implemented in 10 tools; the EPN URL built by hand in 9 tools + 3 client files; the lot/reprint title filter forked four ways; the signup handler inlined three ways across 31 pages. `tools/_lib/{markers,epn,filters}.mjs` + one `js/signup.js`.
6. The Python page factory (`tools/topps-release-watcher/`, 5,665 lines, five frozen `content_*.py` snapshots) is dead under the freeze — move to `tools/archive/` so `git ls-files tools` reads as the live toolchain.
7. `tools/price-audit.yml` and `tools/price-engine/price-snapshot.yml` are stale copies of the live workflows and have diverged. Delete.

None of 2–7 needs Mo. They are one Wednesday build session, and they are queued in STATE as such.
