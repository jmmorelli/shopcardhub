Legend & Methodology

SCOPE — the secret tier: all 49 beyond-base slots (#132-180) - 32 SIRs (the full Eeveelution run), 12 URs, 5 Hyper Rares. Universe = 49, fully priced. Pokémon pull rates differ across rarity tiers, so no equal-supply claim is made — this is a price-weighted chase-basket index, plainly. · WEIGHT — price ÷ basket value (priced cards only). · PRICE — sold comps only, dated per row; never asks, never blended, never estimated. · INDEX LEVEL — basket value ÷ divisor (44.7686), set at inception so the index launched at 100.00: the level IS the cumulative return. The divisor adjusts (and is logged) whenever the basket composition changes, so only prices move the level. · ★ — Track in your Vault (free, no account): Hunting or I Own It. · NO CALLS — ShopCardHub retired Pokémon price calls on Aug 18, 2026 (graded record: no edge). An index is a measurement, not a recommendation.
