Legend & Methodology

PRICE — last sold comp (SportsCardsPro raw solds, as-of stamped). Italic + e = estimated (ask-median fallback or modeled for this mockup); never blended with solds. · FLOAT — listed copies across tracked marketplaces (the engine's live listing counts). Free-float weighting: weight by tradeable supply, not print run. · MKT CAP — price × float. · WK Δ / MO Δ — rank change vs 1 week / 1 month prior; "—" = not ranked in that period; 0 = unchanged. · ENTRY — date the card entered the top 100. · ★ — Track in the Vault (Hunting or I Own It).
INDEX LEVEL — total float cap ÷ divisor. Divisor set at inception so the index launched at 100.00 — at base 100 the level IS the cumulative return (104.27 = +4.27%). Divisor adjusted at every reconstitution so holdings changes never move the level — only prices do. · BUFFER — a card enters at float-cap rank ≤ 90 and exits below rank 110, preventing boundary churn. · TAIL PRICING — holdings without a 30-day sold carry the last sold forward with an age stamp; ask-median fallback is labeled ask-basis.
MOCKUP — Aug 23, 2026. Board prices are real Aug 18 SCP sold reads; floats, tail prices, index level, history and sparklines are modeled for layout. In production the ★ Track button uses the Vault Track contract (Hunting / I Own It + cost, engine auto-link, GA event) and Live Listings deep-links eBay with EPN tracking. An index is a measurement, not a recommendation — calls live on the board and the scorecard, not here.
