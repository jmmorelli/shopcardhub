Legend & Methodology

PRICE — last sold comp (SportsCardsPro raw solds, as-of stamped). Italic + e = estimated (ask-median fallback or modeled for this mockup); never blended with solds. · BASE CHROME — every holding is the standard Bowman Chrome Prospects card (BCP-###): chromium stock, non-auto, unnumbered. In Bowman products "base" alone is ambiguous — collectors often read it as the paper card (BP-###). This index tracks CHROME, the hobby benchmark version. Until 2026 Bowman Chrome streets (Sep 9), marks use paper solds; they transition to Chrome solds ~2–3 weeks after street, same benchmark-transition rule as the Bangers board. · WEIGHT — price ÷ basket value (Σ of the 100 prices). Base cards print in ~equal quantity within a set, so price-weighting IS market-cap weighting up to the unknown constant — stated plainly instead of pretending we know the print run. · FLOAT — listed copies across tracked marketplaces. A DEPTH STAT ONLY, never in the weight: listing counts move for non-price reasons (flip behavior, relists) and the level must move on prices alone. Thin float = hard to buy; fat float = overhang. · WK Δ / MO Δ — rank change vs 1 week / 1 month prior; "—" = not ranked in that period; 0 = unchanged. · ENTRY — date the card entered the top 100. · ★ — Track in the Vault (Hunting or I Own It).
INDEX LEVEL — total float cap ÷ divisor. Divisor set at inception so the index launched at 100.00 — at base 100 the level IS the cumulative return (104.27 = +4.27%). Divisor adjusted at every reconstitution so holdings changes never move the level — only prices do. · BUFFER — a card enters at price rank ≤ 90 and exits below rank 110, preventing boundary churn. · TAIL PRICING — holdings without a 30-day sold carry the last sold forward with an age stamp; ask-median fallback is labeled ask-basis.
MOCKUP — Aug 23, 2026. Board prices are real Aug 18 SCP sold reads; floats (depth stat), tail prices, index level, history and sparklines are modeled for layout. Weighting: price ÷ basket value; the parallels sub-tab (phase 2) uses true print-run cap weighting since /50-style runs are printed on the card. In production the ★ Track button uses the Vault Track contract (Hunting / I Own It + cost, engine auto-link, GA event) and Live Listings deep-links eBay with EPN tracking. An index is a measurement, not a recommendation — calls live on the board and the scorecard, not here.
