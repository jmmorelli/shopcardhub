Legend & Methodology

SCOPE — the secret tier beyond the 217-card base (runs to #295). All 70 secret-tier slots (#218–#295 chase tier) enumerated and priced as of the 08/31/26 re-mark — the build-time API truncation was closed out via PriceCharting console enumeration, each entry through a logged divisor adjustment. Pokémon pull rates differ across rarity tiers, so no equal-supply claim is made — this is a price-weighted chase-basket index, plainly. · WEIGHT — price ÷ basket value (priced cards only). · PRICE — sold comps only, dated per row; never asks, never blended, never estimated. · INDEX LEVEL — basket value ÷ divisor (54.1102), set at inception so the index launched at 100.00: the level IS the cumulative return. The divisor adjusts (and is logged) whenever the basket composition changes, so only prices move the level. · ★ — Track in your Vault (free, no account): Hunting or I Own It. · NO CALLS — ShopCardHub retired Pokémon price calls on Aug 18, 2026 (graded record: no edge).
