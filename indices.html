▮ Set Indices · How each set we track is doing, in one number

Every Set We Track. One Number Each.

Every index started at 100. Above 100, the cards in that index got pricier; below 100, cheaper. Click any row to see the cards.

Every live index is built from real sold prices, each dated, and every card behind them is on its page. The screener ranks every live ticker by its 1-week, 1-month and 3-month move; the sector boards below carry the detail. An index measures prices; it doesn't tell you what to buy.

Methodology on every index page: price-weighted over sourced sold reads (PriceCharting for Pokémon, SportsCardsPro/eBay solds for sports) · unpriced universe cards carry zero weight and enter via logged divisor adjustments · Pokémon: 100 = the set's release month, or for vintage sets the first month PriceCharting's sold history reliably covers (rebased Sep 30, 2026; months before our live marks are reconstructed monthly from that history and drawn dashed) · charts on a log scale · re-marked Monday (chase tiers) or Monday and Thursday. Affiliate disclosure: listing links on index pages are EPN-tracked; prices and index math are independent of them.
