Legend & Methodology

SCOPE — the secret tier of the Team Rocket set: all 62 beyond-base slots (#183-244). 45 carry sourced sold reads; the rest await a first listing. This page is the set's home on ShopCardHub - index-first. Pokémon pull rates differ across rarity tiers, so no equal-supply claim is made — this is a price-weighted chase-basket index, plainly. · WEIGHT — price ÷ basket value (priced cards only). · PRICE — sold comps only, dated per row; never asks, never blended, never estimated. · FULL METHODOLOGY — solds vs asks vs engine marks vs proxies, the one-page read: /how-prices-work · INDEX LEVEL — basket value ÷ divisor (17.7884), set at inception so the index launched at 100.00: the level IS the cumulative return. The divisor adjusts (and is logged) whenever the basket composition changes, so only prices move the level. · ★ — Track in your Vault (free, no account): Hunting or I Own It. · NO CALLS — ShopCardHub retired Pokémon price calls on Aug 18, 2026 (graded record: no edge).
