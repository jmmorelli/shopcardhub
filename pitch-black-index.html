Legend & Methodology

SCOPE — the secret tier: all 36 beyond-base slots (#85–120). Universe = 36; the basket = every card with a sourced sold read. Pokémon pull rates differ across IR/UR/SIR/MHR, so no equal-supply claim is made — PB26 is a price-weighted chase-basket index, plainly. The 84-card base set is phase 2. · WEIGHT — price ÷ basket value (priced cards only). Unpriced cards carry zero weight until their first sourced mark; each enters via a divisor adjustment so inclusion never moves the level. · PRICE — PriceCharting ungraded sold comps, dated. Never blended with asks. · INDEX LEVEL — basket value ÷ divisor (7.12). Set at inception so the index launched at 100.00: the level IS the cumulative return. The divisor adjusts if the universe ever changes so only prices move the level. · SINCE LAUNCH — real documented reads only (set launch Jul 17 → Aug 17 marks); "—" = no launch-window read exists, and none is invented. · ★ — Track in your Vault (free, no account): Hunting or I Own It. · NO CALLS — ShopCardHub retired Pokémon price calls on Aug 18, 2026 (graded record: no edge). An index is a measurement, not a recommendation. This page will never tell you to buy a card; it tells you what the tape did.
